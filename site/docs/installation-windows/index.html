Installation: Windows

This guide installs GoEasyERP on a Windows computer with Docker Desktop. For Linux and macOS see Installation: Linux and macOS.

You need Windows 10 22H2 or Windows 11 (64-bit), about 4 GB of free memory and 10 GB of disk, and virtualization enabled in the BIOS/UEFI (Task Manager → Performance → CPU shows “Virtualization: Enabled”).

Install

  1. Install Docker Desktop with “Use WSL 2” checked, restart when asked, and start Docker Desktop until it shows “Engine running”.
  2. In PowerShell: 
    mkdir C:\GoEasyERP; cd C:\GoEasyERP
Invoke-WebRequest https://raw.githubusercontent.com/hansjlachmann/goeasyerp/main/docker-compose.local.yml -OutFile docker-compose.yml
notepad docker-compose.yml      # replace JWT_SECRET with any long random text, save
docker compose up -d
  3. After 2–3 minutes open http://localhost:8000 and create the first user.

Check that docker info --format "{{.OSType}}" prints linux. If it prints windows, right-click the Docker icon in the taskbar and choose “Switch to Linux containers”.

Stop GoEasyERP with docker compose stop and start it again with docker compose start, in C:\GoEasyERP. It also starts whenever Docker Desktop runs; to start Docker Desktop at sign-in, tick Settings → General → “Start Docker Desktop when you sign in”.

Never run docker compose down -v. It deletes the database.

This installation is reachable from this computer only. To open it from other computers, change the line "127.0.0.1:8000:80" in docker-compose.yml to "8000:80", set ORIGIN to http://<computer name>:8000 and open port 8000 in the Windows firewall.

Docker Desktop is free for personal use, education and small businesses (fewer than 250 employees and less than USD 10 million annual revenue). Larger companies need a paid Docker subscription, or can use Docker Engine in WSL2, which is free.

Upgrade

Download docker-compose.local.yml again and save it over docker-compose.yml, keeping your JWT_SECRET. Then, in C:\GoEasyERP:

docker compose pull
docker compose up -d

Demo data

To look around with sample data, GoEasyERP can fill a company with demo customers and a year of customer ledger entries.

  1. Create a company, for example demo01 with the display name “Demo Company 01”, and switch to it with Ctrl+O.
  2. Add a Job Queue line with Object ID to Run 901 and Parameter SMALL (20 customers, about 540 ledger entries).
  3. Run it with F9.

Never run it in a company with real data. If the company already has customers, it deletes the company’s data first.

Windows Server

Docker Desktop is not supported on Windows Server, and the Docker Engine there runs Windows containers only, which cannot run GoEasyERP. Use Docker Engine in WSL2 (Windows Server 2022 and 2025), or a Linux virtual machine in Hyper-V, which is the better choice for a server several people use. In Ubuntu or the Linux VM:

curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER   # log out and in again
mkdir ~/goeasyerp && cd ~/goeasyerp
curl -o docker-compose.yml https://raw.githubusercontent.com/hansjlachmann/goeasyerp/main/docker-compose.local.yml
nano docker-compose.yml         # replace JWT_SECRET
docker compose up -d

With Docker Engine in WSL2, Windows also needs a port forwarding to WSL (netsh interface portproxy) before other computers can reach it; a Linux VM does not. For a server with HTTPS and backups, follow the server installation in Installation: Linux and macOS, inside Ubuntu or the Linux VM.
