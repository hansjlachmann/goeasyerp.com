Installation: Windows

This guide installs GoEasyERP on a Windows computer with Docker Desktop. For Linux and macOS see Installation: Linux and macOS.

You need Windows 10 22H2 or Windows 11 (64-bit), about 4 GB of free memory and 10 GB of disk, and virtualization enabled in the BIOS/UEFI (Task Manager → Performance → CPU shows “Virtualization: Enabled”).

Install

  1. Install Docker Desktop with “Use WSL 2” checked, restart when asked, and start Docker Desktop until it shows “Engine running”.
  2. In PowerShell, run this one line: 
    irm https://raw.githubusercontent.com/hansjlachmann/goeasyerp/main/scripts/goeasyerp.ps1 | iex
  3. After 2–3 minutes open http://localhost:8000 and create the first user.

The script works in the folder C:\GoEasyERP. To use another folder, run $env:GOEASYERP_DIR = 'D:\GoEasyERP' before the line. It checks that Docker runs Linux containers, keeps the settings in a file called .env (a new installation gets a random JWT_SECRET), downloads the latest docker-compose.yml and starts GoEasyERP. If it stops with an error, the message says what to fix; then run the line again.

To read the script before it runs, download it and run the file:

Invoke-WebRequest https://raw.githubusercontent.com/hansjlachmann/goeasyerp/main/scripts/goeasyerp.ps1 -OutFile goeasyerp.ps1
notepad goeasyerp.ps1
powershell -ExecutionPolicy Bypass -File goeasyerp.ps1

If the script says Docker runs Windows containers, or docker info --format "{{.OSType}}" prints windows, right-click the Docker icon in the taskbar and choose “Switch to Linux containers”.

Stop GoEasyERP with docker compose stop and start it again with docker compose start, in C:\GoEasyERP. It also starts whenever Docker Desktop runs; to start Docker Desktop at sign-in, tick Settings → General → “Start Docker Desktop when you sign in”.

Never run docker compose down -v. It deletes the database. Keep JWT_SECRET in .env: it also encrypts stored passwords, so it must never change.

This installation is reachable from this computer only. To open it from other computers, add these lines to .env:

GOEASYERP_BIND=0.0.0.0
GOEASYERP_ORIGIN=http://<computer name>:8000

Then run docker compose up -d in C:\GoEasyERP and open port 8000 in the Windows firewall. GOEASYERP_PORT changes the port.

Docker Desktop is free for personal use, education and small businesses (fewer than 250 employees and less than USD 10 million annual revenue). Larger companies need a paid Docker subscription, or can use Docker Engine in WSL2, which is free.

Without the script

Save docker-compose.local.yml as docker-compose.yml in a folder of its own, and create a file .env next to it with the line JWT_SECRET=<any long random text>. Then, in that folder:

mkdir C:\GoEasyERP; cd C:\GoEasyERP
Invoke-WebRequest https://raw.githubusercontent.com/hansjlachmann/goeasyerp/main/docker-compose.local.yml -OutFile docker-compose.yml
notepad .env                    # add the line JWT_SECRET=... and save
docker compose up -d

Upgrade

Run the same one line again. It backs the database up into the backups folder when GoEasyERP is running, keeps your .env settings, saves the new docker-compose.yml (the old one stays as docker-compose.yml.bak) and restarts GoEasyERP.

irm https://raw.githubusercontent.com/hansjlachmann/goeasyerp/main/scripts/goeasyerp.ps1 | iex

Without the script, save the new docker-compose.local.yml over docker-compose.yml; the settings stay in .env. Then, in C:\GoEasyERP:

docker compose pull
docker compose up -d

Demo data

To look around with sample data, GoEasyERP can fill a company with demo customers and a year of customer ledger entries.

  1. Create a company, for example demo01 with the display name “Demo Company 01”, and switch to it with Ctrl+O.
  2. Add a Job Queue line with Object ID to Run 901 and Parameter SMALL (20 customers, about 540 ledger entries).
  3. Run it with F9.

Demo data never deletes real data. Creating it marks the company as a demo company. Running it again in a demo company replaces that company’s data, but only for a user with the role SUPER, from the page with F9, after a question. A scheduled run never replaces data, and a company with customers that is not a demo company is refused.

Windows Server

Docker Desktop is not supported on Windows Server, and the Docker Engine there runs Windows containers only, which cannot run GoEasyERP. Use Docker Engine in WSL2 (Windows Server 2022 and 2025), or a Linux virtual machine in Hyper-V, which is the better choice for a server several people use. In Ubuntu or the Linux VM:

curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER   # log out and in again
curl -fsSL https://raw.githubusercontent.com/hansjlachmann/goeasyerp/main/scripts/goeasyerp.sh | sh

With Docker Engine in WSL2, Windows also needs a port forwarding to WSL (netsh interface portproxy) before other computers can reach it; a Linux VM does not. For a server with HTTPS and backups, follow the server installation in Installation: Linux and macOS, inside Ubuntu or the Linux VM.
