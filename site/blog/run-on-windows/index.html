Run GoEasyERP on your Windows workstation

11 November 2026

You can run GoEasyERP on your own Windows workstation.

Prerequisite: you need Docker Desktop configured to “Use WSL 2”.

The installation itself is four PowerShell commands, which you can copy from the installation guide.

The guide also shows how to upgrade, how to load sample data to look around with, and how to install on Windows Server.

GoEasyERP · open source under the MIT licence · goeasyerp.org
